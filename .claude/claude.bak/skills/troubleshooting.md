## OLED 0.91寸 128×32 只有3行显示 (2026-06-23)

**现象**: `OLED_Draw_Line()` 传入 line=0 或 line=4 的参数时，对应行不显示任何内容，静默失败。

**原因**: 本项目的 OLED 是 **128×32** 像素（0.91寸），字体 7×10，最多显示 3 行。
`bsp_oled.c` 中 `OLED_Draw_Line()` 有行号校验：
```c
if (line > 0 && line <= 3)  // 只接受 1/2/3
```
传入 0 或 >3 直接被忽略，没有任何编译警告或运行时提示。

**解决**: 所有 OLED 显示只用 line 1/2/3。行号对应 Y 坐标 = `10 * (line - 1)`，即 line1→y=0, line2→y=10, line3→y=20。

**教训**: 写 OLED 显示代码前先看清硬件分辨率。如果是 128×64 的 OLED 则有 6 行可用，本项目的 128×32 只有 3 行。
